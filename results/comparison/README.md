# Controlled comparison outputs

The official TXT, JSON, and CSV files combine the two 20-trial method summaries. The comparison uses a stricter harmonized four-field success definition for both methods and a common empirical per-location reference for image-space repeatability.

The preserved compare_aruco_vs_yolo.py file is byte-identical to the authoritative analysis script and retains the original project topology. Its outputs are the publication source of truth in this directory.
